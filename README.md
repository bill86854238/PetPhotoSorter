# 🐶 Pet Photo Sorter (二季與四季的照片管家)

這是一個專為寵物家庭設計的智慧影像管理工具。透過 AI 技術，自動為您的狗狗照片進行分類、標記並生成細膩的文字描述，讓珍貴的成長紀錄更易於珍藏。

---

## 🌟 核心功能

- **精準身分識別**：結合 YOLOv8 與 CLIP 模型，自動辨識並區分「二季」與「四季」兩隻狗狗。
- **在地 AI 描述**：整合 **Ollama (Qwen2.5-VL)**，在不洩露隱私的情況下，為每張照片生成繁體中文的情境描述。
- **智慧分類體系**：支援依據年齡（幼犬/成犬）、動作（站立/坐下/活動）與拍攝日期自動歸檔。
- **NAS 存取優化**：針對網路硬碟 (SMB/Tailscale) 環境優化，具備檔案掃描快取機制，大幅提升存取效率。
- **跨平台支援**：自動偵測執行環境（macOS/Windows），智慧切換網路路徑。
- **品質保障**：內建 aHash 重複偵測與「潛在誤判」標記功能，確保分類準確性。

## 🚀 快速開始

### 1. 環境準備
請確保您的電腦已安裝 Python 3.9+，並安裝必要套件：
```bash
pip install ultralytics transformers torch torchvision pillow opencv-python numpy
```

### 2. 啟動 AI 服務 (選配)
若需開啟文字描述功能，請安裝 [Ollama](https://ollama.com/) 並下載模型：
```bash
ollama pull qwen2.5-vl:7b
```

### 3. 設定個人參數
本專案使用 `config.json` 進行管理（可參考 `config_example.json`）：
- 設定 NAS 的 IP 位址與資料夾路徑。
- 調整 AI 提示詞 (Prompt) 與分類門檻。

### 4. 開始整理
```bash
python pet_sorter.py
```

---

## 🛠 技術規格

- **偵測模型**：YOLOv8 (yolov8n.pt)
- **分析模型**：CLIP (openai/clip-vit-base-patch32)
- **視覺語言模型**：Ollama (預設 Qwen2.5-VL:7b)
- **檔案處理**：支援 .jpg, .jpeg, .png, .webp 圖片及主流影片格式 (.mp4, .mov)

